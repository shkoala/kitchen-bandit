# The Fridge Bandit

Игра для устной отработки английской лексики и грамматики на уровне A1–A2.

1. Выберите режим. Дайте ученикам время рассмотреть продукты и назвать несколько из них. Наведите курсор на продукт или коснитесь его на экране, чтобы увидеть английское название.
2. Нажмите **Let the cat in!** и посмотрите, что утащил кот.
3. После устного ответа нажмите **Open the fridge**. Под холодильником появится ответ, а на полке будет видно пустое место.
4. Нажмите **One more!** для следующего раунда. Кот забирает продукты по одному в случайном порядке. Режимы запоминают ход игры до закрытия или перезагрузки вкладки.

| Режим | Что говорим |
| --- | --- |
| **Some, any, a, an** | *We’ve got an egg. We’ve got some cheese. We haven’t got any cheese left.* |
| **Containers** | *A bottle of water, a packet of biscuits, a cone of ice cream.* Во втором режиме можно засчитать и *an ice cream cone*. |

## Запуск

Распакуйте архив и откройте `index.html` в браузере. Игра работает и без интернета. Звук можно включить на верхней панели.

Для GitHub Pages загрузите в корень репозитория все файлы и папки из архива. В настройках Pages в качестве источника выберите **Deploy from a branch**, ветку **main** и папку **/ (root)**. [Справка GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

Отдельные иллюстрации лежат в `assets/`. Продукты, позы кота, корпус и обе стороны дверцы имеют прозрачный фон. Лицензии шрифтов лежат в `assets/fonts/`.
